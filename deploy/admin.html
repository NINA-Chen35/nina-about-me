一鍵發布到網站

把最新內容直接推送到 GitHub，
Vercel 會在 30 秒內自動更新網站。

⚙️ 先完成 GitHub 設定

  1. 前往 設定 頁面
  2. 找到「GitHub 自動發布設定」區塊
  3. 填入 GitHub 用戶名、Repo 名稱、PAT
  4. 儲存後回來點「一鍵發布」

📥 備用：手動下載

如果一鍵發布失敗，可以手動下載後上傳到 GitHub。

🔄 這台裝置的資料跟網站上的不一致？

後台編輯的內容會先存在「這台瀏覽器」裡，跟其他裝置或網站上實際發布的版本可能不同步。如果覺得畫面跟網站對不起來，可以捨棄這台裝置暫存的內容，重新抓一次網站目前真正上線的資料。
